# MikuBox v0.2.5

本轮为一次全仓扫描后的集中修复:外部导入的确认防线、订阅链接解码补全、隧道状态的真实性,以及一批在特定操作下触发的崩溃。

## 导入与订阅

- 其他应用或网页发来的 `clash://`、`ss://`、`vmess://` 等链接,以及 `v2rayng://` 安装链接,现在先弹确认框再导入。框内只显示协议和域名,不显示账号密码或路径;取消即不导入。从分享面板发来的文本仍直接导入(用户主动选择了本应用)。
- 导入失败不再使应用崩溃,节点凭据也不再写入会随崩溃报告分享的日志。
- `wireguard://` 分享链接首次可被解析导入;SOCKS 链接中 base64 编码的账号密码不再被丢弃。
- 首次拉取失败的订阅保留在列表中,可从编辑页重试;失败的订阅不会阻挡其他订阅的导入与更新。
- 「添加 [HTTP]」表单修复了无法保存的问题;地址含不可见特殊字符时保存会报错而不是崩溃。

## 隧道

- 连接期间网络不再被整台设备视为计费网络(metered),Wi-Fi 下「仅限不计费网络」的下载与同步任务恢复正常。
- 主页与快捷磁贴的状态广播不再接受其他应用发送,第三方应用无法伪造「已连接」状态或出口 IP。
- 连接过程中进程被杀(如系统低内存)会计入重连退避:坏配置不再每 30 秒无限重试,三次失败后暂停,可手动重连。

## 界面与其他

- 横幅/头像裁剪可用(uCrop 界面缺失导致的必崩已修复)。
- 桌面开关快捷方式与 Tasker 动作在主进程执行,开关快捷方式现在能真正停止隧道。
- WebDAV 备份/恢复接上已保存的服务器配置(此前无论怎么配置都失败)。
- 日志页在核心输出量大时不再整页空白;相册大图的二维码识别不再卡顿或内存溢出。
- 修复可视化配置编辑器、启动器图标变体、无 VPN 授权对话框系统上的若干边角崩溃。
- 应用数据不再进入系统备份(应用内备份/恢复不受影响)。

## 验证

构建、67 项单元回归与 lint 全部通过;在 API 34 x86_64 模拟器上完成四项实机验收(安装清单核对、深链确认行为、隧道连接/流量/断开、横幅裁剪),全部通过。完整记录见 `docs/testing-2026-10-04.md`。

已知限制:订阅下载与备份导入暂无大小上限;Go 侧测试仍由 CI 覆盖,本机不跑。
